  Windows 版 OpenCut — 超简单说明
═══════════════════════════════════════

【一句话】
Mac 做不出 Windows 安装包，要用 GitHub 免费云端帮你打。
做一次就行，以后可重复用。

───────────────────────────────────────
你需要准备
───────────────────────────────────────
✔ 一个 GitHub 账号（免费，像网盘注册一样）
✔ 本文件夹里的：OpenCut-源码-上传GitHub.zip

───────────────────────────────────────
第 1 步：注册 GitHub（2 分钟）
───────────────────────────────────────
浏览器打开：github.com
点 Sign up 注册（有账号就直接登录）

───────────────────────────────────────
第 2 步：上传代码（3 分钟）
───────────────────────────────────────
1. 打开：github.com/new
2. 名字填：opencut
3. 选 Public → Create repository
4. 点页面上的「uploading an existing file」
5. 双击解压 OpenCut-源码-上传GitHub.zip
6. 把解压出来的所有东西拖进网页
7. 点绿色 Commit changes

───────────────────────────────────────
第 3 步：下载 Windows 安装包（等 15 分钟）
───────────────────────────────────────
1. 点网页顶部的 Actions
2. 左边点 Build OpenCut
3. 点 Run workflow → 再点 Run workflow
4. 等出现绿色 ✓（约 10~15 分钟）
5. 点进去 → 往下滚 → Artifacts
6. 下载 OpenCut-Windows
7. 解压，里面有个 setup.exe

→ 把这个 setup.exe 发给 Windows 用户就行了！

───────────────────────────────────────
【备选】如果你有 Windows 电脑
───────────────────────────────────────
把整个 opencut 文件夹拷到 Windows 电脑
打开终端运行：
  npm install
  npm run build
安装包在：
  src-tauri\target\release\bundle\nsis\

───────────────────────────────────────
【重要】更新不会丢数据
───────────────────────────────────────
你的截图和文本不在安装包里，在系统文件夹里：

Mac：
  ~/Library/Application Support/com.opencut.desktop/clips/

Windows：
  C:\Users\你的用户名\AppData\Roaming\com.opencut.desktop\clips\

覆盖安装 / 更新新版本 → 数据还在。
不要删上面这个 clips 文件夹。
