# 更新后数据会丢吗？

**不会。** OpenCut 的数据和安装包是分开存放的。

## 数据存在哪

| 平台 | 路径 |
|------|------|
| Mac | `~/Library/Application Support/com.opencut.desktop/clips/` |
| Windows | `%APPDATA%\com.opencut.desktop\clips\` |

里面是：
- 图片文件（`.png` / `.jpg`）
- `texts.json`（文本记录）
- `image_metadata.json`（分类信息）

## 更新 / 重装会怎样

| 操作 | 数据 |
|------|------|
| 安装新版本覆盖旧版 | ✅ 保留 |
| 从菜单栏/托盘退出再打开 | ✅ 保留 |
| 重启电脑 | ✅ 保留 |
| 删除 clips 文件夹 | ❌ 会丢（别删） |
| 卸载后重装（未删 clips） | ✅ 保留 |

## 自动迁移

每次启动时，OpenCut 会自动从以下旧位置**合并**数据（只增不删）：

- 旧版标识 `com.opencut.app` 的数据目录
- 早期 `uploads/` 文件夹
- Web 开发版 `Downloads/opencut/uploads`

所以你从 Web 版或旧版升级，历史记录也会尽量保留。

## 手动备份（可选）

复制整个 `clips` 文件夹到 U 盘即可备份全部数据。
